# 🚗 Carpooling Expo App

This is a carpooling mobile application built using **React Native**, **Expo**, and **Firebase Authentication**. The app is developed as part of our Agile Team Project.

---

## 📂 Folder Structure

```
/MyExpoApp
 ├── /app
 ├── /assets
 ├── /components
 ├── App.js
 ├── app.json
 ├── firebaseAuth.tsx
 └── ...
```

---

## 🛠️ Prerequisites

Ensure you have the following installed:

- Node.js (>=14.x)
- npm or yarn
- Expo CLI:  
  ```bash
  npm install -g expo-cli
  ```
- Firebase project with **Email/Password Authentication** enabled

---

## 🚀 Installation Steps

1. **Clone the repository**
   Create a Folder named Ecoride 

```bash
git clone https://github.com/ABHINAV-GOPINADH/carpooling.git

git checkout expo

```

2. **Install dependencies**

```bash
npm install
```

### Required dependencies

```bash
npm install firebase
npm install @react-navigation/native
npm install @react-navigation/native-stack
npm install react-native-screens react-native-safe-area-context
npm install expo-splash-screen
npm install expo-status-bar
npm install expo-linear-gradient
npm install react-native-gesture-handler
```

---

## ▶️ Running the App

1. Start the Expo development server:

```bash
npx expo start
```

2. Scan the QR code that appears in the terminal or web browser.

3. Open **Expo Go** on your Android/iOS device and scan the QR code to view the app.

---

## ⚙️ Firebase Configuration

Configure your `firebaseAuth.tsx` file with your Firebase credentials:

```tsx
import { initializeApp } from "firebase/app";
import { getAuth } from "firebase/auth";

const firebaseConfig = {
  apiKey: "YOUR_API_KEY",
  authDomain: "YOUR_AUTH_DOMAIN",
  projectId: "YOUR_PROJECT_ID",
  storageBucket: "YOUR_STORAGE_BUCKET",
  messagingSenderId: "YOUR_MESSAGING_SENDER_ID",
  appId: "YOUR_APP_ID"
};

const app = initializeApp(firebaseConfig);
export const auth = getAuth(app);
```

---

## 📝 Notes

- The app uses **Firebase Email/Password Authentication**.
- Handles common Firebase auth errors (e.g., `auth/email-already-in-use`).
- No native builds are required (runs directly on Expo Go).
- Optimized for Agile development workflows.
